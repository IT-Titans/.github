# IT Titans

IT Titans GmbH is a software company from Leer, Germany. We develop software
with .NET and on Azure for our customers and work in their teams as developers.
Under the name IT Titans Software we also build tools of our own. The ones we
publish as open source are on this page.

Website: https://it-titans-gmbh.com/en/

## Repositories

Every public repository belongs to one class, named in the **Status** line of
its README. The class says what you can expect from the repository. The rules
behind the classes are in our
[repository standard](https://github.com/IT-Titans/.github/blob/main/docs/repository-standard.md).

## Reporting a vulnerability

Do not open a public issue. Open the affected repository, select the
**Security** tab and then **Report a vulnerability**. The report stays private
between you and the maintainers. The details are in our
[security policy](https://github.com/IT-Titans/.github/blob/main/SECURITY.md).
