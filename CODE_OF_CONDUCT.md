# Code of conduct

The repositories of the IT-Titans organization adopt the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as their code of conduct.

It applies to issues, pull requests, reviews and every other space of these
repositories, and to everyone who takes part in them, maintainers included.

## Reporting

Report behaviour that violates the code of conduct to IT Titans GmbH through
the contact form at https://it-titans-gmbh.com/en/contact-us/. Start the message
with the words "Code of Conduct", name the repository and add a link to the
issue, pull request or comment concerned.

We handle reports as the enforcement section of the Contributor Covenant
describes and respect the privacy of the person who reports.

For abuse or harassment on GitHub you can also use
[GitHub's own reporting](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam).
