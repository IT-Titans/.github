# Support

This page applies to every repository of the IT-Titans organization that does
not carry a `SUPPORT.md` of its own.

The repositories are provided as they are. We read issues in product and
maintained repositories and answer as time allows; there is no guaranteed
response time for anything except security reports.

## Where to go

| You have | Do this |
|---|---|
| A question about using a repository | Read its README first. If the README is wrong or leaves the question open, that is a documentation bug: open a bug report. |
| A bug | Open an issue with the bug report form. |
| An idea or a request | Open an issue with the feature request form. |
| A security problem | Follow the security policy under the **Security** tab of the repository. Never open a public issue. |
| A commercial question, for example licensing, consulting or paid support | Use the contact form at https://it-titans-gmbh.com/en/contact-us/. |

## Frozen repositories

A repository whose README states the class "frozen" is an example or proof of
concept in its final state. It is archived, which makes it read-only: issues
and pull requests cannot be opened, and we do not answer questions about it.
The README says when and with which tool versions the example was last
verified.
